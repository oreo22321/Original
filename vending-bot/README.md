# Discord 自販機 Bot

Discord のサーバーに「自販機」パネルを置き、デジタル商品 (シリアルコード・ダウンロードリンクなど) を販売する Bot です。
支払いは**管理者が確認してから承認する方式**なので、銀行振込・各種送金サービスなど、どの支払い方法でも使えます。

## できること

- **自販機パネル**: 商品・価格・在庫をメニューで表示。商品や在庫を変えると自動で更新されます (最大 125 商品)
- **在庫制の商品**: 1 行 = 1 個 (コードなど)。注文時に在庫を予約するので、同時に買われても二重に売れません
- **無制限の商品**: 全員に同じ内容 (ダウンロードリンクなど) を渡します
- **ロール付与**: 購入した人にロールを自動で付けられます (ロールだけを売ることもできます)
- **承認制**: 注文は確認チャンネルに届き、「承認」で商品が購入者の DM に届きます。「却下」すると理由を通知して在庫を戻します
- **購入者の操作**: 確認待ちの注文のキャンセル、`/history` での購入履歴と受け取った商品の再表示 (DM を閉じている人も受け取れます)
- **売上と注文の一覧**: `/sales`・`/orders`
- Bot を再起動しても、以前に設置したパネルや承認ボタンはそのまま使えます

## 購入の流れ

```
購入者                         Bot                         管理者 (確認チャンネル)
  │ パネルで商品を選ぶ ─────────▶ 価格・支払い方法を表示
  │ 代金を支払う
  │ 「購入手続きへ」→ 数量と
  │  支払いの確認情報を入力 ───▶ 在庫を予約して注文を作成 ──▶ 注文 #12 (承認 / 却下)
  │                                                          │ 入金を確認して「承認」
  │ ◀──────────── DM で商品を受け取る ◀── 在庫を販売済みにする ◀┘
```

## 準備

### 1. Bot を作る

1. [Discord Developer Portal](https://discord.com/developers/applications) で **New Application** を作成
2. **Bot** → **Reset Token** でトークンを表示してコピー (他人に見せないこと)
3. 特権インテント (Privileged Gateway Intents) は**どれも不要**です
4. 次の URL の `CLIENT_ID` を **General Information** の Application ID に置き換えて開き、サーバーに招待します

```
https://discord.com/oauth2/authorize?client_id=CLIENT_ID&scope=bot+applications.commands&permissions=268553216
```

付与される権限: チャンネルを見る・メッセージを送信・埋め込みリンク・ファイルを添付・メッセージ履歴を読む・ロールの管理 (ロール付与を使わないなら外して構いません)

### 2. 起動する

Python 3.10 以上が必要です。

```sh
cd vending-bot
python -m venv .venv
source .venv/bin/activate        # Windows は .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # .env の DISCORD_TOKEN= にトークンを書く
python bot.py
```

`ログインしました` と表示されれば起動しています。Bot を動かしている間だけ販売できるので、常に電源が入っている PC・VPS・Raspberry Pi などで動かしてください。

| 設定 (.env) | 内容 |
| --- | --- |
| `DISCORD_TOKEN` | Bot のトークン (必須) |
| `DATABASE_PATH` | データの保存先。省略すると `data/vending.db` |
| `SYNC_GUILD_ID` | 開発用。指定したサーバーにだけコマンドを登録し、すぐ反映します |
| `MAX_QUANTITY` | 1 回の注文で買える最大数 (既定 50) |
| `MAX_PENDING_ORDERS` | 1 人が同時に持てる確認待ちの注文数 (既定 3) |

### 3. サーバーで設定する

1. **`/setup channel`** — 注文が届くチャンネルを指定します。購入者に見えないチャンネルにしてください。`role` を指定すると、そのロールの人も承認・却下できます
2. **`/setup payment`** — 購入者に表示する支払い方法 (振込先など) を入力します
3. **`/product add`** — 商品名・価格・説明を入力します。購入者にロールを付けるなら `role` を指定します
4. **`/stock add`** — 在庫を 1 行に 1 個ずつ入力します。大量にあるときは `file` に .txt を添付します
5. **`/panel`** — 販売用のチャンネルで実行すると、自販機パネルが設置されます

## コマンド

管理用のコマンドは「サーバー管理」権限を持つ人にだけ表示されます (サーバー設定 → 連携サービス で変えられます)。

| コマンド | 内容 |
| --- | --- |
| `/setup channel` `/setup payment` `/setup show` | 確認チャンネル・担当ロール・支払い方法の設定と確認 |
| `/product add` `/product edit` `/product role` `/product remove` `/product list` | 商品の追加・変更・ロール設定・販売終了・一覧 |
| `/stock add` `/stock export` `/stock clear` | 在庫の追加・ファイルで書き出し・取り出し (取り出した在庫はファイルで返ります) |
| `/panel` | 自販機パネルを設置 (見出しと説明文を変えられます) |
| `/orders` | 注文の一覧 (確認待ち・完了・却下・キャンセル・すべて) |
| `/sales` | 売上の合計と商品別の内訳 |
| `/history` | **誰でも使えます。** 自分の購入履歴・受け取った商品の再表示・確認待ちの注文のキャンセル |

## 注意

- データはすべて `data/vending.db` (SQLite) に保存されます。定期的にコピーしてバックアップしてください
- 支払いの確認は管理者が手動で行います。自動化したい場合は、公式の API がある決済サービス (Stripe など) と組み合わせてください
- 販売する商品と販売のしかたが、Discord の利用規約・コミュニティガイドラインや法律 (特定商取引法など) に沿っているか確認してください

## テスト

Discord に接続せずに、在庫の予約・承認・却下・キャンセルの流れと、コマンドやボタンが Discord の制限内に収まっているかを確かめます。

```sh
pip install pytest
python -m pytest
```
