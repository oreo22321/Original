# 🛒 Discord ショップ Bot（販売・代行）

Discord サーバーで **デジタル商品の販売** と **代行サービスの受付** をするための Bot です。
`/setup` を 1 回実行するだけで、ショップ用のロール・チャンネル・購入パネルがそろったサーバーができあがります。

## できること

| 機能 | 内容 |
| --- | --- |
| 🏗️ サーバー自動構築 | `/setup` でロール・カテゴリ・チャンネル・権限・ルール文・各パネルを一括作成 |
| ✅ 認証 | ボタンを押した人だけがショップやコミュニティを見られる（荒らし対策） |
| 🛍️ 商品販売 | 商品一覧パネルのメニューから選ぶ → 数量入力 → お客様専用の注文チャンネルが自動で作られる |
| 🧾 代行受付 | 「依頼する」ボタン → 内容・予算・納期を入力 → 専用チャンネルでスタッフが見積もり |
| 💰 支払い確認 | 設定した支払い案内（PayPay・振込など）を表示。スタッフが入金を確認してボタンを押す |
| 📦 納品 | 商品に登録した納品内容（コード・URL など）が自動入力される。チャンネルと DM に送信、購入者ロールを付与 |
| 📉 在庫管理 | 支払い確認時に在庫が減り、売り切れはメニューから自動で消える。キャンセル時は在庫が戻る |
| ⭐ レビュー | 納品後にお客様が ★1〜5 とコメント → 「実績・レビュー」チャンネルに自動投稿 |
| 📜 ログ | 注文・見積もり・支払い・納品・キャンセルを記録。チャンネルを閉じるとき会話ログを txt で保存 |
| 📊 売上集計 | `/stats` で売上合計・件数・平均評価 |

### 注文の流れ

```
商品:  選ぶ → [お支払い待ち] → スタッフが支払い確認 → [対応中] → 納品 → [納品済み] → レビュー → 閉じる
代行:  依頼 → [見積もり待ち] → スタッフが見積もり → [お支払い待ち] → …（以下同じ）
```

お客様は **支払い前ならキャンセル可能**。支払い後のキャンセルはスタッフのみです。
1 人が同時に開ける注文は 3 件まで（`/config limit` で変更可）。

## はじめかた

### 1. Bot を作る（Discord Developer Portal）

1. <https://discord.com/developers/applications> を開き、右上の **New Application** → 名前を入れて作成
2. 左メニュー **Bot** を開く
   - **Reset Token** を押してトークンをコピー（**誰にも見せないでください**。漏れたらすぐ Reset）
   - 下の **Privileged Gateway Intents** で **MESSAGE CONTENT INTENT** を **ON** にして保存
     （注文チャンネルの会話ログを保存するために使います）
3. 左メニュー **OAuth2** → **OAuth2 URL Generator**
   - SCOPES: `bot` と `applications.commands` にチェック
   - BOT PERMISSIONS: `Manage Roles` `Manage Channels` `View Channels` `Send Messages` `Manage Messages` `Embed Links` `Attach Files` `Read Message History`
   - 一番下の URL を開いて、自分のサーバーに招待

> 起動時、まだどのサーバーにも入っていなければ招待 URL がコンソールに表示されます。

### 2. Bot を動かす

[Node.js](https://nodejs.org/ja)（20.12 以上、LTS 版でOK）をインストールしてから:

```bash
cd discord-bot
npm install
cp .env.example .env      # Windows は copy .env.example .env
```

`.env` をメモ帳などで開き、`DISCORD_TOKEN=` の後ろにトークンを貼って保存。

```bash
npm start
```

`🤖 ○○ としてログインしました` と出れば成功です。

### 3. サーバーで設定する

| 順番 | やること |
| --- | --- |
| ① | サーバーで `/setup` を実行 → チャンネルとロールが作られます |
| ② | **サーバー設定 → ロール** で、Bot のロールを「スタッフ」「購入者」「認証済み」より **上** にドラッグ（下だとロールを付けられません） |
| ③ | `/config payment` で支払い方法を登録（例: PayPay ID・振込先・「送金後スクショを送ってください」） |
| ④ | スタッフにする人に「スタッフ」ロールを付ける |
| ⑤ | `/product add` で商品を登録 → 商品一覧パネルが自動で更新されます |
| ⑥ | 「📌｜ルール」の文章を自分のお店に合わせて書き直す（Bot のメッセージを消して、自分で投稿し直せばOK） |

### 作られるサーバー構成

```
📢 インフォメーション   … 誰でも見える
   📌｜ルール  📣｜お知らせ  ✅｜認証
🛒 ショップ             … 認証した人だけ
   🛍️｜商品一覧  🧾｜代行依頼  ⭐｜実績・レビュー
💬 コミュニティ         … 認証した人だけ
   💬｜雑談  ❓｜質問
🎫 チケット             … 注文ごとの専用チャンネルがここに作られる（本人とスタッフだけ）
🔒 スタッフ             … スタッフだけ
   📋｜スタッフ連絡  📜｜ログ
ロール: スタッフ / 購入者 / 認証済み
```

`/setup` は何度実行しても大丈夫です（同じ名前のものは作り直さず、権限だけ直します）。

## コマンド一覧

| コマンド | 使える人 | 説明 |
| --- | --- | --- |
| `/setup` | 管理者 | サーバーを自動構築 |
| `/product add` | 管理者 | 商品を追加（名前・価格・在庫・説明・絵文字・納品内容） |
| `/product edit` | 管理者 | 商品を編集（変えたい項目だけ入力。`unlimited:True` で在庫無制限） |
| `/product remove` / `list` | 管理者 | 削除 / 一覧 |
| `/panel shop` / `service` / `verify` | 管理者 | パネルを好きなチャンネルに設置 |
| `/config payment` | 管理者 | 支払い方法の案内文 |
| `/config roles` / `channels` / `limit` / `show` | 管理者 | ロール・チャンネル・同時注文数・設定確認 |
| `/order list` / `info` / `cancel` | スタッフ | 注文の一覧・詳細（履歴つき）・キャンセル |
| `/stats` | 管理者 | 売上集計 |
| `/shop` | 誰でも | 商品一覧を自分だけに表示して購入 |

> 「管理者」= サーバー管理権限を持つ人。サーバー設定 → 連携サービス から、コマンドを使える人を変更できます。

### 納品内容について

`/product add` の `delivery` にコードや URL を入れておくと、スタッフが「納品する」を押したときに自動で入力されます（送信前に編集もできます）。
1 個ずつ違うコードを送る商品は、`delivery` を空にして、納品時にスタッフが入力してください。ファイルを渡したいときは注文チャンネルに直接添付してください。

## 24 時間動かすには

Bot は **起動している間だけ** 動きます。PC を閉じると止まります。

| 方法 | 料金の目安 | 向いている人 |
| --- | --- | --- |
| 自分の PC | 無料 | まずはお試し |
| [Railway](https://railway.com) などのホスティング | 月 数百円〜 | 手軽に常時稼働したい |
| VPS（ConoHa・さくら・Xserver VPS など） | 月 数百円〜 | 自分で管理できる人・安定重視 |
| Render の **Background Worker**（有料プラン） | 月 $7〜 | Render を使い慣れている人 |

どのサービスでも設定は同じです:
- ルートディレクトリ: `discord-bot`
- ビルドコマンド: `npm install`
- 起動コマンド: `npm start`
- 環境変数: `DISCORD_TOKEN` にトークン

⚠️ **データの保存について**: 注文や商品は `data/db.json` に保存されます。ホスティングによっては再起動でファイルが消えるので、**永続ボリューム（Volume / Disk）** を付けて、環境変数 `DATA_FILE` をその中のパス（例: `/data/db.json`）にしてください。
VPS や自分の PC なら、そのままで大丈夫です（`data/` フォルダをときどきバックアップするのがおすすめ）。

## 運営するときの注意

- **Discord の利用規約・コミュニティガイドライン** を守ってください。アカウント・Nitro の売買や、ゲーム・各サービスの規約に違反する代行は、Discord や相手サービスの規約違反となり、サーバーや Bot が停止される場合があります。
- 継続して有償で販売する場合、**特定商取引法に基づく表記**（販売者名・連絡先・返品条件など）が必要になることがあります。「📌｜ルール」などに掲載しておきましょう。
- 売上が一定以上になると**確定申告**が必要です。`/stats` や「📜｜ログ」を記録に使えます。
- トークンは絶対に公開しないでください（`.env` は Git に含まれない設定になっています）。

## 開発者向け

```bash
npm test        # ストア・在庫・注文フローのテスト
npm run check   # Discord に接続せず、コマンド定義やパネルが作れるか確認
```

```
src/
  index.js               起動・コマンド登録・振り分け
  store.js               データ保存（商品・注文・設定）
  commands/              スラッシュコマンド
  handlers/components.js ボタン・メニュー・入力フォーム
  lib/                   注文カード・チケット・パネル・ログなど
```
