# 🛒 Discord ショップ Bot（販売・代行）

Discord サーバーで **商品の販売** と **代行の受付** を自動化する Bot です。
商品の表示 → 注文チケット作成 → 支払い確認 → 商品の受け渡し → レビュー までを Bot がやります。

---

## 📱 スマホだけで導入（PC なし・だいたい 20 分）

スマホでは Bot のプログラムを動かし続けられないので、**Railway**（Bot を 24 時間動かしてくれるサービス）に置きます。
全部スマホのブラウザ（Safari / Chrome）と Discord アプリでできます。

> 💴 Railway は最初に $5 分の無料お試しがあり、その後は **Hobby プラン 月 $5**（$5 分の利用料込み。この Bot ならほぼ収まります）。料金は変わることがあるので [公式の料金ページ](https://railway.com/pricing) で確認してください。

### ① Bot を作る（Discord Developer Portal）

1. ブラウザで <https://discord.com/developers/applications> を開いてログイン
   - 画面が崩れるときは **PC 版表示** に切り替え（Safari: アドレスバーの「ぁあ」→「デスクトップ用 Web サイトを表示」／Chrome: 「⋮」→「PC 版サイト」）
2. **「New Application」** → 名前を入れて **Create**
3. **General Information** の **APPLICATION ID** をコピーしてメモ帳に貼っておく（③で使う）
4. 左メニュー（☰）→ **Bot**
   - **MESSAGE CONTENT INTENT** を **ON** → **Save Changes**
   - **Reset Token** → **Copy**（メモ帳に一時的に貼っておく。**人に見せない**）

### ② Railway で Bot を動かす

1. ブラウザで <https://railway.com> → **Login** → **GitHub でログイン**
2. **New Project** → **Deploy from GitHub repo** → このリポジトリ（`Original`）を選ぶ
   - リポジトリが出てこないときは「Configure GitHub App」から Railway にアクセスを許可
3. できた四角（サービス）をタップ → **Settings**
   - **Root Directory** に `discord-bot` と入力
   - **Branch**（Source の所）で、この Bot のファイルがあるブランチを選ぶ（main にマージ済みなら main のままで OK）
4. **Variables** → **New Variable**
   - 名前: `DISCORD_TOKEN`　値: ① でコピーしたトークン → **Add**
5. **データ用のボリュームを付ける**（これをしないと、更新のたびに商品や注文が消えます）
   - プロジェクト画面の **「+ Create」**（または「+」）→ **Volume** → この Bot のサービスを選ぶ
   - **Mount path** に `/data` → 作成
   - Bot が自動でボリュームを見つけて、そこに保存します
6. 画面上の **Deploy**（または「Apply changes」）を押す
7. **Deployments** → 一番上の **View Logs** に `🤖 ○○ としてログインしました` と出れば成功

### ③ サーバーに入れる

ログに出ている **招待 URL** をタップ。ログが見づらいときは、下の URL の `ここにAPPLICATION_ID` を ① でメモした ID に置き換えてブラウザで開いてください:

```
https://discord.com/oauth2/authorize?client_id=ここにAPPLICATION_ID&permissions=268561424&scope=bot+applications.commands
```

サーバーを選んで **認証**。

### ④ Discord アプリでショップを作る

Discord アプリのチャット欄で `/setup` → あとは下の「ステップ 4」と同じです。
商品登録・支払い確認・納品・クーポン・お知らせなど、**運営はすべてスマホの Discord アプリでできます**。

### スマホ運営のコツ

| やりたいこと | 方法 |
| --- | --- |
| コードを大量に登録 | メモアプリでコードを 1 行ずつ書いて `.txt` で保存 → `/codes add` の `file` に添付（少ないなら `file` なしで入力欄に貼り付け） |
| 商品画像を付ける | 画像共有サイト（Imgur など）にアップして、画像の URL を `/product edit` の `image_url` に貼る（Discord に投稿した画像の URL は期限が切れて表示されなくなるので使えません） |
| 注文が入ったら気づきたい | 「スタッフ」ロールを自分に付けておくと、注文・支払い報告のたびにメンションで通知が来ます |
| データのバックアップ | `/backup` でファイルを受け取って保存 |
| Bot が止まっていないか確認 | Railway のアプリ画面（ブラウザ）で Deployments を見る。止まっても自動で再起動する設定になっています |
| Bot を最新版にする | GitHub のファイルが更新されると、Railway が自動で入れ直します |

> Android なら Termux というアプリでスマホ自体で動かす方法もありますが、スマホの電源やアプリが止まると Bot も止まるのでおすすめしません。iPhone ではできません。

## 🚀 かんたん導入（PC で動かす場合・だいたい 10 分）

### ステップ 1：Bot を作る（5 分）

1. <https://discord.com/developers/applications> を開いてログイン
2. 右上の **「New Application」** → 好きな名前（例: `〇〇ショップ`）→ **Create**
3. 左のメニューの **「Bot」** を押す
4. 画面の下の方にある **「MESSAGE CONTENT INTENT」** を **ON（青）** にして **Save Changes**
5. 同じページの上の方にある **「Reset Token」** → **Yes** → 出てきた長い文字を **Copy**
   （これが Bot の「パスワード」です。**絶対に人に見せない**でください）

### ステップ 2：Bot を起動する（3 分）

1. [Node.js](https://nodejs.org/ja) の **LTS** 版をインストール（最初の 1 回だけ）
2. この GitHub のページで緑の **「Code」→「Download ZIP」** → ZIP を展開
3. `discord-bot` フォルダを開いて、
   - **Windows** → `start.bat` を **ダブルクリック**
   - **Mac** → `start.command` を **右クリック →「開く」**
4. 黒い画面に **「トークン:」** と出たら、ステップ 1 でコピーした文字を **貼り付けて Enter**
   （保存されるので、次回からは聞かれません）

### ステップ 3：サーバーに入れる（1 分）

黒い画面に **招待 URL**（`https://discord.com/oauth2/authorize?...`）が表示されるので、
それをブラウザで開いて、自分のサーバーを選んで **「認証」**。

### ステップ 4：ショップを作る（1 分）

サーバーのチャット欄で:

```
/setup
```

→ チャンネル・ロール・購入パネルが全部自動でできます。あとは画面の案内どおりに:

1. **サーバー設定 → ロール** で、Bot のロールを一番上の方へドラッグ
2. `/config payment` → 支払い方法（PayPay ID・振込先など）を入力
3. `/product add` → 商品を登録

**これで完成です！** 🎉
困ったら、サーバーで `/help` と打つと使い方が出ます。

> 💡 黒い画面を閉じたり PC をスリープすると Bot も止まります。24 時間動かしたいときは [下の「24 時間動かすには」](#24-時間動かすには) を見てください。

## できること

### 🛍️ 商品の表示
- 商品一覧パネルに、カテゴリごとに商品・価格・在庫を表示（商品を変えると自動で更新）
- 商品を選ぶと、画像・説明つきの詳細カードが出て、そこから購入
- 商品が 26 個以上になると、自動で「カテゴリ → 商品」の 2 段階メニューに切り替え
- 新商品・再入荷を「お知らせ」チャンネルに自動投稿

### 🎫 チケット（注文チャンネル）
- 購入・依頼すると、**お客様とスタッフだけが見える専用チャンネル**が自動で作られる
- 状態（お支払い待ち → 対応中 → 納品済み → 完了）がボタンつきのカードで分かる
- 閉じるときに会話の記録をログに保存してからチャンネルを削除

### 💰 支払い確認
- 設定した支払い方法の案内を自動で表示
- お客様が **「支払いました」** ボタンで報告 → スタッフに通知
- スタッフが入金を確認して **「支払いを確認」** を押す
- 放置された未払い注文は 24 時間で自動キャンセル（時間は変更可）

### 📦 商品の受け渡し（自動納品）
| 商品のタイプ | 設定方法 | 受け渡し |
| --- | --- | --- |
| 1 個ずつ違うコード（ギフトコード・シリアルなど） | `/codes add` でコードを登録（txt ファイルで大量登録も OK） | 支払い確認と同時に **自動で 1 人ずつ違うコード** を送る。在庫 = 残りコード数 |
| 全員同じもの（ダウンロード URL・テンプレなど） | `/product add` の `delivery` に入力 | 支払い確認と同時に **自動で送る** |
| その都度用意するもの | 何も入れない | スタッフが「納品する」を押して内容を入力 / ファイルはチャンネルに添付 |

受け渡し内容は **注文チャンネル** と **お客様の DM** の両方に届き、「購入者」ロールが自動で付きます。

### 🧾 代行
「依頼する」ボタン → 内容・予算・納期を入力 → スタッフが見積もり → 支払い → 納品

### 🧰 便利機能
| 機能 | コマンド |
| --- | --- |
| 割引クーポン（％引き・円引き・回数・期限・商品限定） | `/coupon create` |
| セール・営業時間などのお知らせ投稿 | `/announce` |
| 売上合計・件数・平均評価 | `/stats` |
| お客様の注文履歴 | `/myorders` |
| いたずら・未払いの人を注文禁止に | `/blacklist add` |
| 認証ボタン（荒らし対策） | `/setup` で自動設置 |
| レビュー（★1〜5）を実績チャンネルに自動投稿 | 納品後にボタン |

## 24 時間動かすには

| 方法 | 料金の目安 | ひとこと |
| --- | --- | --- |
| 自分の PC | 無料 | お試し向け。PC を付けている間だけ動く |
| [Railway](https://railway.com) などのホスティング | 月 数百円〜 | GitHub とつなぐだけで動く |
| VPS（ConoHa・さくら・Xserver VPS など） | 月 数百円〜 | 安定。少しだけ知識が必要 |

ホスティングでの設定（どこでもほぼ同じ）:
- ルートディレクトリ: `discord-bot`
- ビルドコマンド: `npm install` ／ 起動コマンド: `npm start`
- 環境変数: `DISCORD_TOKEN` = トークン
- ⚠️ データは `data/db.json` に保存されます。再起動でファイルが消えるサービスでは **Volume（永続ディスク）** を付けて、環境変数 `DATA_FILE` を `/data/db.json` のようにその中にしてください

## よくあるトラブル

| 症状 | 直し方 |
| --- | --- |
| 「MESSAGE CONTENT INTENT が有効になっていません」 | ステップ 1-4 の設定を ON にして保存 → もう一度起動 |
| 「トークンが正しくありません」 | Developer Portal で Reset Token → 起動し直すと再入力を求められます |
| `/setup` などのコマンドが出てこない | Bot が起動しているか確認。Discord アプリを再起動（Ctrl+R） |
| 「ロールを付けられませんでした」 | サーバー設定 → ロール で Bot のロールを「スタッフ」「購入者」「認証済み」より上に |
| お客様に DM が届かない | お客様の DM 設定が閉じています。注文チャンネルには必ず投稿されるので大丈夫です |
| Mac で start.command が開けない | 右クリック →「開く」。だめならターミナルで `bash start.command` |

## 運営するときの注意

- **Discord の利用規約・コミュニティガイドライン** を守ってください。アカウント・Nitro の売買や、ゲーム・各サービスの規約に違反する代行は、Discord や相手サービスの規約違反となり、サーバーや Bot が停止される場合があります。
- 継続して有償で販売する場合、**特定商取引法に基づく表記**（販売者名・連絡先・返品条件など）が必要になることがあります。「📌｜ルール」などに掲載しておきましょう。
- 売上が一定以上になると**確定申告**が必要です。`/stats` や「📜｜ログ」を記録に使えます。
- 支払いは自動では確認できません（PayPay の個人送金や振込は Bot から見えないため）。入金はスタッフが必ず自分の目で確認してから「支払いを確認」を押してください。
- トークンは絶対に公開しないでください（`.env` は Git に含まれない設定になっています）。

## 開発者向け

```bash
npm install
npm start       # 起動 (トークンが無ければ入力を求める)
npm test        # データ処理のテスト
npm run check   # Discord に接続せずに、コマンド定義・パネルが作れるか確認
```

```
src/
  index.js               起動・コマンド登録・振り分け・自動キャンセル
  store.js               データ保存（商品・コード在庫・クーポン・注文・設定）
  commands/              スラッシュコマンド
  handlers/components.js ボタン・メニュー・入力フォーム
  lib/                   注文カード・チケット・パネル・納品・お知らせなど
```
