Luau Obfuscator

独自バイトコードVM 方式の難読化ツール

Luau / Lua のスクリプトを独自バイトコードVMへ変換し、制御構造・変数名・文字列を復元困難にします。 難読化後は同梱エンジンで実行して元と同じ動作か自動検証。Roblox / エグゼキューターの API にも対応します。

VM 方式は元のコードを線形バイトコード（ジャンプで制御フローを平坦化）へ変換し、埋め込みVMで実行します。 命令列は位置依存の鍵で符号化され、定数はチェックサム連動の鍵スケジュールで暗号化（単一平文キーなし・改ざんで壊れる）。if/while/for の形・変数名・文字列は出力に残りません。 Roblox / エグゼキューターの API を含むどんなコードも難読化でき、対応できない構文は自動的に従来方式へ切り替わります（＝必ず動く）。 「API名の隠蔽」をオンにすると game や hookfunction などの API 名も暗号化し、実行時に環境（getgenv / getfenv など）から解決します。

自作コードの保護・学習用途向け。他人のコードの無断改変や不正利用には使わないでください。
